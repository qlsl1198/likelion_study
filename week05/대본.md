# 5주차 강의 대본 — H2부터 PostgreSQL까지 (실습 한 줄 코스)

**예상 시간**: 약 3시간  
**준비물**: 4주차 프로젝트 또는 Spring Initializr, 모든 사람 **H2 + PostgreSQL 의존성** 동시에 넣어둠  

교안 순서는 **`presentation.md`** Lab 번호와 같다.

---

## 오프닝 (3분)

> "저번 시간 데이터는 재시작하면 사라졌어요. 이번엔 DB에 두고요. 오늘이 흔한 순서예요 — **설치 간단한 H2 로 먼저 맞춰 보고**, 같은 코드 그대로 **PostgreSQL 같은 실무 친숙한 DB 로 옮깁니다**. Java 파일은 거의 안 건드립니다."

한 줄 규칙: `@Entity` = 표 하나, `spring.profiles.active` 로 **저장소만 갈아끼운다.**

---

## Lab 0 — 의존성 (10분)

> "starter 에 Web, Data JPA, **H2, PostgreSQL 둘 다** 넣어둘게요. 어차피 나중 단계 가야 하니까요."

실행까지 확인 (`./mvnw spring-boot:run`).

---

## Lab 1 — 프로필 + H2 (15분)

1. 세 파일 패턴 설명 (`application.properties` + `*-h2` + `*-pg`)  
2. 콘솔 접속 JDBC URL 과 properties **복붙 검사** 단원에서 집중 점검  

---

## Lab 2~4 — 엔티티 · Repository · Service · Controller (50분 내외)

코드 블록은 스크린에 **materials.md** 또는 교안 노트 링크.  
> "플로우 지난주랑 동일합니다. 메모리 `List` 빼고 `repository.save()` 넣었다고 생각하세요."

메모리용 Todo 클래스 남아 있으면 하나만 두라고 명시한다.

---

## Lab 5 — Postman · H2 (10분)

> "네 단계 고정: 빈 목록 → POST 한 건 → GET → **서버 끈 뒤 다시 켜서 GET** 까지"

---

## Lab 6 — PostgreSQL 전환 — 수업 후반 블록 (35~45분)

> "이제 진짜 DB 서버예요. `CREATE DATABASE tododb;` 까지만 보여 준 뒤, **password 칸**만 수정해요."

1. 프로필 `pg` 로 바꾸기 한 줄 보여 줌  
2. 기동 에러 패턴 세 가지 짚기: 비번, 포트, DB 이름 미생성  
> "안에 데이터 안 옮겨 와도 돼요. 새 프로젝트니까 새로 POST 하면 된다 설명 추가"

Lab 7에서 Postman 같은 URL 재검증 시간 짧게.
