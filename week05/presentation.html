@Entity 한 줄 요약

클래스 한 개 ≈ 표 한 줄. repository.save(), findAll() 로 CRUD 패턴 시작.

# application.properties

@Table(name = "todos")
public class Todo {

    private Long id;
    @Column(nullable = false)
    private String title;
    // ...
}
