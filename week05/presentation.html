Todo 엔티티 코드 (1/2)

@Entity
@Table(name = "todos")
public class Todo {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 200)
    private String title;

    @Column(length = 1000)
    private String description;

    private boolean completed;

    private LocalDateTime createdAt;

Todo 엔티티 코드 (2/2)

    protected Todo() {
    }

    public Todo(String title, String description) {
        this.title = title;
        this.description = description;
        this.completed = false;
        this.createdAt = LocalDateTime.now();
    }

    public Long getId() { return id; }
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    public String getDescription() { return description; }
    public void setDescription(String description) { this.description = description; }
    public boolean isCompleted() { return completed; }
    public void setCompleted(boolean completed) { this.completed = completed; }
    public LocalDateTime getCreatedAt() { return createdAt; }
}

Lab 4. Repository 만들기

package com.likelion.todoapi.domain;

import org.springframework.data.jpa.repository.JpaRepository;

import java.util.List;

public interface TodoRepository extends JpaRepository<Todo, Long> {

    List<Todo> findByCompleted(boolean completed);

    List<Todo> findByTitleContainingIgnoreCase(String keyword);
}

JpaRepository가 주는 기본 기능

메서드역할
findAll()전체 조회
findById(id)id로 단건 조회
save(todo)저장 또는 수정
deleteById(id)id로 삭제
count()개수 조회

쿼리 메서드 이름 규칙

List<Todo> findByCompleted(boolean completed);

Spring Data JPA는 메서드 이름을 읽고 이런 SQL에 가까운 쿼리를 만듭니다.

SELECT * FROM todos WHERE completed = ?;
List<Todo> findByTitleContainingIgnoreCase(String keyword);

제목에 특정 단어가 포함된 Todo를 대소문자 구분 없이 찾습니다.

Lab 5. Service 만들기 (1/3)

package com.likelion.todoapi.service;

import com.likelion.todoapi.domain.Todo;
import com.likelion.todoapi.domain.TodoRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Service
public class TodoService {

    private final TodoRepository todoRepository;

    public TodoService(TodoRepository todoRepository) {
        this.todoRepository = todoRepository;
    }

Service 만들기 (2/3)

    public List<Todo> getAll() {
        return todoRepository.findAll();
    }

    public Todo get(Long id) {
        return todoRepository.findById(id).orElseThrow();
    }

    @Transactional
    public Todo create(String title, String description) {
        Todo todo = new Todo(title, description);
        return todoRepository.save(todo);
    }

Service 만들기 (3/3)

    @Transactional
    public Todo toggleCompleted(Long id) {
        Todo todo = todoRepository.findById(id).orElseThrow();
        todo.setCompleted(!todo.isCompleted());
        return todo;
    }

    @Transactional
    public void delete(Long id) {
        todoRepository.deleteById(id);
    }

    public List<Todo> getByCompleted(boolean completed) {
        return todoRepository.findByCompleted(completed);
    }

    public List<Todo> searchByTitle(String keyword) {
        return todoRepository.findByTitleContainingIgnoreCase(keyword);
    }
}

@Transactional은 언제 붙이나?

  • create: DB에 새 행을 저장함
  • toggleCompleted: 기존 행의 값을 바꿈
  • delete: 행을 삭제함
DB 데이터를 바꾸는 메서드에는 우선 @Transactional을 붙인다고 기억하면 됩니다.

Lab 6. Controller 만들기 (1/4)

package com.likelion.todoapi.controller;

import com.likelion.todoapi.domain.Todo;
import com.likelion.todoapi.service.TodoService;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;
import java.util.Map;

@RestController
@RequestMapping("/api/todos")
public class TodoController {

    private final TodoService todoService;

Controller 만들기 (2/4)

    public TodoController(TodoService todoService) {
        this.todoService = todoService;
    }

    @GetMapping
    public List<Todo> list() {
        return todoService.getAll();
    }

    @GetMapping("/{id}")
    public Todo one(@PathVariable Long id) {
        return todoService.get(id);
    }

Controller 만들기 (3/4)

    @PostMapping
    public ResponseEntity<Todo> create(@RequestBody Map<String, String> body) {
        String title = body.getOrDefault("title", "").trim();
        String description = body.getOrDefault("description", "");

        if (title.isBlank()) {
            return ResponseEntity.badRequest().build();
        }

        Todo saved = todoService.create(title, description);
        return ResponseEntity.status(HttpStatus.CREATED).body(saved);
    }

    @PatchMapping("/{id}/toggle")
    public Todo toggle(@PathVariable Long id) {
        return todoService.toggleCompleted(id);
    }

Controller 만들기 (4/4)

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> remove(@PathVariable Long id) {
        todoService.delete(id);
        return ResponseEntity.noContent().build();
    }

    @GetMapping("/search")
    public List<Todo> search(
        @RequestParam(required = false) Boolean completed,
        @RequestParam(required = false) String keyword
    ) {
        if (completed != null) return todoService.getByCompleted(completed);
        if (keyword != null && !keyword.isBlank()) return todoService.searchByTitle(keyword);
        return todoService.getAll();
    }
}

Lab 9. PostgreSQL로 전환

application-pg.properties에서 비밀번호를 수정합니다.

spring.datasource.url=jdbc:postgresql://localhost:5432/tododb
spring.datasource.username=postgres
spring.datasource.password=설치할때정한비밀번호
spring.datasource.driver-class-name=org.postgresql.Driver
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect

application-pg.properties 작성 체크

  • tododb 철자가 DB 이름과 같은가?
  • postgres 사용자가 맞는가?
  • password가 설치 때 정한 비밀번호와 같은가?
  • 포트가 기본값 5432인가?
  • PostgreSQLDialect 줄이 들어 있는가?
비밀번호는 GitHub에 올리지 않습니다. 과제 제출 시 예시 파일만 올리거나 README에 “로컬 비밀번호 사용”이라고 적습니다.

프로필 한 줄만 바꾸기

application.properties에서:

spring.profiles.active=pg

서버 재실행:

./mvnw spring-boot:run
Java 코드는 수정하지 않습니다. 바뀐 것은 DB 연결 설정뿐입니다.

Spring Boot 실행 로그에서 볼 것

실행 후 터미널에서 아래 내용을 확인합니다.

  • 에러 없이 서버가 Started ... 상태로 뜨는지
  • HikariPool 관련 에러가 없는지
  • password authentication failed가 없는지
  • database "tododb" does not exist가 없는지

서버가 정상 기동되면 PostgreSQL 연결은 1차 성공입니다.

PostgreSQL에 테이블 생겼는지 확인

Spring Boot를 pg 프로필로 실행한 뒤 확인합니다.

\c tododb
\dt
select * from todos;

처음에는 테이블만 있고 데이터가 없을 수 있습니다.

H2의 데이터가 PostgreSQL로 자동 복사되지 않습니다. PostgreSQL 상태에서 다시 POST해야 합니다.

PostgreSQL 검증

H2 때와 같은 URL을 다시 호출합니다.

  1. GET /api/todos
  2. POST /api/todos
  3. GET /api/todos
  4. PATCH /api/todos/{id}/toggle
  5. GET /api/todos/search?completed=true
  6. DELETE /api/todos/{id}

H2 데이터가 PostgreSQL로 자동 복사되지는 않습니다. PostgreSQL에서 새로 POST합니다.

최종 설치 체크리스트

  • PostgreSQL 서버가 켜져 있다.
  • tododb 데이터베이스가 있다.
  • Spring Boot의 application-pg.properties 비밀번호가 맞다.
  • spring.profiles.active=pg로 실행했다.
  • Postman에서 POST /api/todos가 성공했다.
  • pgAdmin 또는 psql에서 todos 테이블을 확인했다.

오늘 핵심 정리

  1. @Entity를 만들면 테이블과 연결된다.
  2. JpaRepository를 상속하면 기본 CRUD가 생긴다.
  3. H2는 빠른 연습용으로 좋다.
  4. PostgreSQL은 실제 서비스와 더 가까운 DB다.
  5. Spring Profile을 쓰면 같은 코드로 DB를 바꿔 끼울 수 있다.
