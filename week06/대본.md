# 6주차 강의 대본 — React에서 Spring API 부르기 (실습 위주)

**예상 시간**: 약 2.5시간  
**준비물**: 5주(또는 4주) 백엔드가 `./mvnw spring-boot:run` 으로 뜸, Node 설치된 PC  

강사는 **`presentation.md`** Lab 번호 순으로 화면·터미널 공유하면 됩니다. CORS 이름은 잠깐만 언급하고 **Lab 0 바로 시작**.

## Lab 3 — `App.js` 통째로 (25분 — 핵심)

순서를 **외우게**:

1. 두 터미널: 백엔드 실행 + `npm start`  
2. F12 네트워크 탭 연 다음 새로고침  
3. 목록 확인 → 추가 → 목록 증가  

**막히는 패턴**:

- 검은 줄 CORS → Lab 0  
- `ECONNREFUSED` → 백엔드 꺼짐 또는 포트 틀림  
- 빈 목록 계속인데 네트워크가 404 → 컨텍스트 경로 `/api` 빠졌을 수 있음  

> "커스텀 훅은 **안 해도** 과제 만점 줄 올린 거예요. 일단 버튼 눌러 동작부터."
