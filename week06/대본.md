# 6주차 강의 대본 — React와 Spring Boot API 연동

**예상 시간**: 약 3시간  
**준비물**: 5주차 Todo API, Node.js, Postman 또는 브라우저 개발자도구  
**수업 목표**: React 화면에서 Spring Boot Todo API를 호출해 목록 조회, 추가, 완료 토글, 삭제까지 구현한다.

---

## 1. 오프닝 (5분)

멘트:

> “지난주에는 Todo API가 DB에 저장되도록 만들었습니다. 오늘은 그 API를 React 화면에서 직접 호출합니다. 이제 Postman이 아니라 브라우저 버튼으로 데이터를 만들고 지우는 단계입니다.”

큰 그림:

```text
Browser (localhost:3000)
  ↓ Axios
React
  ↓ HTTP
Spring Boot (localhost:8080)
  ↓ JPA
DB
```

강조:

- 프론트와 백엔드는 동시에 실행해야 한다.
- 포트가 다르므로 CORS 설정이 필요하다.
- 문제가 나면 Network 탭을 먼저 본다.

---

## 2. 백엔드 단독 확인 (10분)

먼저 5주차 백엔드를 실행한다.

```bash
./mvnw spring-boot:run
```

Postman:

```http
GET http://localhost:8080/api/todos
```

멘트:

> “백엔드가 단독으로 안 되면 React에서 아무리 고쳐도 안 됩니다. 먼저 Postman으로 확인합니다.”

---

## 3. CORS 설정 (20분)

`CorsConfig.java` 작성.

멘트:

> “브라우저는 localhost:3000과 localhost:8080을 다른 출처로 봅니다. 그래서 Spring Boot가 ‘3000번에서 오는 요청은 받아도 된다’고 알려줘야 합니다.”

중요 체크:

- `allowedOrigins("http://localhost:3000")`
- React 포트가 다르면 해당 포트로 수정
- CORS 파일 추가 후 백엔드 재실행

자주 나는 실수:

- 코드는 추가했는데 서버 재실행 안 함
- React가 5173 포트인데 3000만 허용함

---

## 4. React 프로젝트와 Axios (15분)

명령:

```bash
npx create-react-app todo-front
cd todo-front
npm install axios
npm start
```

멘트:

> “Axios는 API 요청을 쉽게 보내게 해주는 도구입니다. 오늘은 fetch 대신 Axios를 씁니다.”

---

## 5. Axios 인스턴스 (10분)

`src/api/axios.js` 작성.

강조:

- `baseURL` 끝에 `/api` 포함
- `api.get('/todos')` → `http://localhost:8080/api/todos`

멘트:

> “API 주소를 매번 길게 쓰지 않으려고 baseURL을 한 번에 잡습니다.”

---

## 6. App.js 한 파일로 먼저 완성 (50분)

순서:

1. state 작성
2. `load()`로 목록 불러오기
3. `handleAdd()`로 추가
4. `handleToggle()`로 완료 상태 변경
5. `handleDelete()`로 삭제
6. JSX 화면 작성

멘트:

> “처음부터 파일을 많이 나누면 오히려 헷갈립니다. 오늘은 먼저 App.js 한 파일로 동작하게 만들고, 이후에 Hook으로 분리합니다.”

확인:

- 화면 처음 로딩 시 GET 요청
- 추가 시 POST 요청
- 완료 토글 시 PATCH 요청
- 삭제 시 DELETE 요청

---

## 7. Network 탭 디버깅 (20분)

시연 순서:

1. F12 → Network
2. 새로고침
3. `todos` 요청 클릭
4. Request URL 확인
5. Status Code 확인
6. Response 확인

멘트:

> “화면만 보면 어디서 실패했는지 모릅니다. Network 탭을 보면 요청이 안 갔는지, 서버가 에러를 냈는지, 응답은 왔는데 화면 처리가 안 된 건지 나뉩니다.”

---

## 8. 자주 나는 오류 설명 (15분)

대표 오류:

- CORS: 서버 허용 문제
- Network Error: 서버 꺼짐/포트 불일치
- 404: `/api` 경로 빠짐
- 400: POST body에 `title` 없음

학생에게 말할 질문:

> “지금 Network 탭에서 Status Code가 몇 번인가요?”

---

## 9. useTodos 훅으로 분리 (25분)

App.js가 동작한 뒤 `hooks/useTodos.js`로 API 호출을 분리한다.

멘트:

> “화면 코드와 API 호출 코드를 나누면 나중에 컴포넌트가 커져도 관리하기 쉽습니다.”

분리 후에도 기능이 같아야 한다.

---

## 10. 인터셉터와 로딩/에러 처리 (15분)

Axios 인터셉터 설명:

> “여러 API에서 공통으로 에러 로그를 찍고 싶을 때 한 곳에 모읍니다.”

UI 원칙:

## 11. 마무리 (5분)

정리:

- CORS는 백엔드 설정이다.
- Axios는 프론트에서 API를 부르는 도구다.
- `baseURL`을 정확히 잡아야 한다.
- 문제가 나면 Network 탭부터 본다.
- 동작한 뒤 Hook으로 분리한다.

과제:

- 목록 조회, 추가, 삭제, 완료 토글 중 최소 3개 이상 구현
- Network 탭 또는 화면 동작 캡처
- README에 백엔드/프론트 실행 명령 작성
- `node_modules/` 제외
