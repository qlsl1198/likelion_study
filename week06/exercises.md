# 6주차 실습 문제

## 비전공·입문자 안내

- **과제 통과 최소선(권장)**: **실습 A** 만 완료해도 제출·채점 대상입니다.  
  - Spring **CORS** 설정 + React에서 **목록 불러오기(GET)** + **한 줄 추가(POST)** + 화면 캡처  
- **실습 B** 는 **커스텀 훅**으로 코드 정리하기 — 시간 있으면.  
- **실습 C~E**는 **삭제**, **인터셉터·에러**, **로딩 UX** 등 **심화·가산점**.

백엔드는 **`GET/POST /api/todos`** (필요 시 `DELETE`) 가 동작하는 프로젝트를 사용합니다.

---

## 실습 A: 화면에서 Todo 불러오기·추가하기 (비전공 권장)

### 목표

`localhost:3000` 과 `localhost:8080` 을 동시에 켠 뒤, **브라우저 한 곳에서** 목록 확인 + 새 항목 추가.

### 체크리스트

1. **백엔드**: `presentation.md` 【Lab 0】 과 같이 CORS 허용 (`http://localhost:3000`)  
2. **프로젝트**: `create-react-app` (또는 Vite+React 허용 — README에 명시)  
3. **`axios` 설치**, `src/api/axios.js` 에 `baseURL` 이 백엔드 `/api` 를 가리키게 설정  
4. **화면**에서 다음이 된다  
   - 첫 로드 때 **목록** 표시 (`GET /todos`)  
   - 입력란에 제목 적고 버튼 → **`POST /todos`** 후 목록이 갱신  

> **커스텀 훅 없이 `App.js` 한 파일만**으로 구현해도 **만점 라인 통과 가능**합니다.

### 제출물

- 프론트 소스 일부 또는 전체 깃 레포 링크  
- **스크린샷**: 화면에 할 일 목록 + 방금 추가한 항목이 보이는 모습 (`Network` 에 200 상태가 보이면 더 좋음)  
- `README.md`: 터미널 두 개 명령 (백엔드 실행, `npm start`)  

---

## 실습 B: 커스텀 훅으로 분리 (선택 권장)

### 목표

API 호출을 `hooks/useTodos.js` 같은 파일로 빼고, 컴포넌트에는 **표시 로직 위주**만 남긴다.

### 제출물

- `useTodos.js`(또는 동일 역할 파일) + 사용하는 컴포넌트  

---

## 실습 C: 삭제까지 (선택)

### 목표

각 행에 **삭제** 버튼 — `DELETE /api/todos/{id}` 후 목록 갱신.

### 제출물

- 동작 녹화 5초 or 스크린샷  

---

## 실습 D: 에러 처리 (선택)

### 목표

다음 중 **2가지**:

- Axios **응답 인터셉터** 에서 `console.error` 또는 `alert` 로 상태 코드 출력  
- 화면에 **한 줄이라도** 사용자용 메시지 (`목록 불러오기 실패` 등)

### 제출물

- 수정 파일 + 브라우저 콘솔 또는 화면 캡처  

---

## 실습 E: 로딩 UX (선택)

### 목표

데이터 받는 동안 `'불러오는 중…'` 같은 문구 또는 버튼 `disabled`.

### 제출물

- 캡처 1장
